# Design source of truth

Keep the current, approved design decisions in this directory. Update them when the design changes, and link any design files or assets that are part of the source of truth. Mark proposals and unresolved questions clearly so they are not mistaken for approved decisions.

## Product and interaction principles

What should the interface consistently help users do? Record navigation, feedback, accessibility and responsive behavior that applies across screens.

## Visual system

Record approved typography, colors, spacing, components and asset usage. Link to the relevant files rather than duplicating values that are enforced in code.

## Key screens and flows

Link to the approved designs for the most important screens and user journeys. Add focused documents in this directory as the design grows.

## Open design questions

List decisions that still need validation or approval.
